# 🌞 SURYA-MED

### Smart Solar-Powered Energy Management System for Rural Healthcare

**Tagline: Power That Puts Healthcare First.**

SURYA-MED is an intelligent solar-powered energy management system proposed to improve electricity reliability in rural healthcare facilities. The system integrates solar energy generation, battery storage, real-time energy monitoring and priority-based power distribution to ensure better utilisation of available electricity during power shortages.

 PROJECT STATUS

Concept development and proposed system architecture.

Hardware integration, software development and performance validation are planned development activities.

The initial demonstration will use LEDs and low-voltage demonstration loads to represent healthcare equipment.

Actual clinical equipment will not be connected to the student demonstration prototype.
